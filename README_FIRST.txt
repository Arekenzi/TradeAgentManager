TradeAgent Manager v25.0.2 — MIGRATION FIX

Что исправлено:
- одноразовый перенос старой Cloudflare базы в Firebase: заявки и их полная история оплат/возвратов, роли, остатки, настройки, фото, нумерация, удаления и доступный журнал действий (до 500 последних событий, ограничение старого API);

- центральная атомарная нумерация заказов через Firestore, без дублей между устройствами;
- presence/last seen пользователей через Firestore;
- пустой localStorage нового GitHub Pages адреса больше не считается успешной миграцией;
- миграция повторяемая и идемпотентная: заявки пишутся по прежним ID, более новые Firebase-записи не затираются.

ОБЯЗАТЕЛЬНО: опубликовать FIRESTORE_RULES.txt в Firebase Console → Firestore Database → Rules.

После публикации версии: войти администратором → Админка → Восстановление старой базы → скачать мост → открыть его локально на Mac → ввести СТАРЫЙ код администратора → полученный JSON выбрать в приложении.
